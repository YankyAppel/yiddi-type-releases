# Yiddi Type

**Yiddi Type** by **Yiddi AI** - Yiddish speech to text, all on your own Windows computer.

Yiddi Type פון Yiddi AI שרייבט אויס אידישע רעקארדינגס (שיעורים, דרשות, טישן) אין Word און טעקסט, מיט מראה מקומות, אן עדיטאר, און "טאק און טייפ". אלעס ארבעט אויף אייער קאמפיוטער, אן אינטערנעט.

### English

Yiddi Type transcribes Yiddish recordings (shiurim, drashos, tishen) into Word and text, with sources (mareh mekomos), an editor and "talk and type". Everything runs on your computer, without internet.

**Download:** open [the latest release](https://github.com/YankyAppel/yiddi-type-releases/releases/latest) and download `YiddiType-…-Setup.exe`.

The program checks here for new versions and updates itself. It is free; each computer gets its own license.

---
This repository holds only the releases (installer, full zip and update packages). It contains no source code.
